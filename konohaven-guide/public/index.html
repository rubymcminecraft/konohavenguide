Konohaven · Update guide

Bring your settings

When you make a new instance for an update, your settings, keybinds and map stay behind in the old one. Copying them over takes a couple of minutes.

  1. Step1

    Launch the new instance once

    Start it, let it reach the title screen, then close it. That creates the folders you'll be pasting into.

  2. Step2

    Open the old instance's folder

    • Modrinth App: right-click the instance, then Open folder
    • CurseForge: right-click the instance, then Open Folder
    • Prism: select the instance, then Folder on the right
    • Vanilla launcher: Installations, hover the install, click the folder icon
  3. Step3

    Copy these

    options.txtvideo settings, keybinds, volume
    configall your mod settings
    journeymapyour explored map and waypoints
    servers.datyour server listOptional
  4. Step4

    Paste into the new instance

    Open the new instance's folder the same way and paste everything in. If it asks, pick Replace.

  5. Step5

    Launch and play

    Your settings, binds and map should all be back.

Couple things

  • Don't copy the mods folder. Those mods are for the old version and will crash the new one.
  • A mod acting weird? Delete just that mod's file inside config and it'll make a fresh one next launch.
  • Close the game first. If it's still open, it can overwrite your files when it shuts down.
